# Good Memories — Design System

Premium event decoration brand. Warm, elegant, celebratory.
Gold + blush pink + deep charcoal. Playfair Display for headings (luxury feel),
Poppins for body. Rounded cards, soft shadows, mobile-first.

## Components
- Hero: full-screen gradient (blush→gold), big headline, 2 CTAs (Book / WhatsApp)
- Service cards: icon + title + desc, hover lift
- Package cards: price, feature list, CTA
- Gallery: responsive grid (placeholder gradients until real photos added)
- Booking: 4-step process strip
- Contact: WhatsApp button + form (mailto/Formspree-ready)
- Footer: brand + social placeholders
